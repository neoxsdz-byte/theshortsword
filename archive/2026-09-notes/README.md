# The Shortsword — Claude's workspace

Everything Claude knows about this novel, kept here so it survives between sessions.
Built 11 September 2026 from a full read of the three Google Docs.

## Files
| File | What's in it |
|---|---|
| `01-story-so-far.md` | Chapter-by-chapter summary, Ch 1–25, plus the Ch 26 notes that aren't written yet |
| `02-characters.md` | Full cast: protagonists, mentors, students, the Godless Hand, military, church, the Order |
| `03-world-and-lore.md` | Deep history, magic system, Ordenmere's geography, the Corruption, factions, Ryn's technology |
| `04-threads-and-open-questions.md` | Where each thread stands, planted seeds, and questions the docs don't answer |
| `05-continuity-flags.md` | Contradictions, numbering problems, editing artifacts left in the manuscript, terminology sweep |
